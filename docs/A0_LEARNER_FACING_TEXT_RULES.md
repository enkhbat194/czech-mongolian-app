# A0 learner-facing text rules

Энэ баримт нь A0 хичээлүүдийн сурагчид шууд харагдах текстийг түгжих дүрэм.

## Гол зарчим

A0 сурагчид эхлээд амьд нөхцөлд хэрэглэх богино хэллэг сурна. Дүрмийн нэр томьёо, сургалтын дотоод түвшин, developer тайлбар нь сурагчийн дэлгэц дээр шууд харагдахгүй.

## Сурагчид харагдах текст дээр хориглох зүйл

Дараах үг, хэллэгийг card explanation, exercise prompt, feedback, dialogue prompt зэрэг learner-facing талбарт оруулахгүй.

- `A0-д`, `A0 дээр`, `A0 түвшинд`
- `staff`
- `formal`
- `chunk`
- `pattern`
- `case`
- `accusative`, `nominative`, `genitive`, `dative`, `locative`, `instrumental`
- `noun`, `verb`, `adjective`, `adverb`, `preposition`

Эдгээрийг data tag, internal audit, developer documentation дотор ашиглаж болно. Харин сурагчийн дэлгэц дээр шууд гаргахгүй.

## Мэргэжлийн нэр томьёо хэрэглэх зайлшгүй тохиолдол

A0 дээр ерөнхийдөө хэрэглэхгүй. Хэрэв зайлшгүй хэрэглэх бол ард нь энгийн монгол тайлбар заавал байна.

Буруу:

```text
Одоо accusative case суръя.
```

Зөв:

```text
“Кофе” гэдэг үг захиалга хэлэх үед “kávu” болж сонсогдоно.
```

Зайлшгүй мэргэжлийн нэртэй хувилбар:

```text
“Заахын тийн ялгал” — юм авах, хүсэх, хэрэглэх үед үгийн хэлбэр өөрчлөгдөх дүрэм.
```

## Сурагчид харагдах зөв хэв маяг

- Богино өгүүлбэр хэрэглэ.
- Нөхцөлөөр нь тайлбарла.
- “Та ингэж хэлнэ”, “ингэж асууна”, “ажилтан ингэж асууж байна” гэсэн хэлбэрийг ашигла.
- Czech хэлбэр өөрчлөгдвөл дүрмийн нэрээр биш, сонсогдох хэлбэрээр тайлбарла.

Жишээ:

```text
Dám si kávu. = Би кофе авъя.
“Кофе” гэдэг үг захиалга хэлэх үед “kávu” болж сонсогдоно.
```

## Internal grammar map

Дүрмийн tag хэрэгтэй. Гэхдээ энэ нь сурагчийн дэлгэцийн text биш, app-ийн арын data байна.

Жишээ internal tag:

```text
grammarTags: ["object-form", "request", "polite-prosím"]
```

Сурагчид харагдах текст:

```text
Цэс өгнө үү. Кафед цэс хүсэхдээ ингэж хэлнэ.
```

## Automatic audit

`scripts/audit-a0-ready.mjs` нь learner-facing талбарууд дээр хориглосон technical үгс орсон эсэхийг шалгана. Энэ шалгалт `npm run check` дотор ажиллана.

Тиймээс A0.8–A0.15 data insert хийхдээ шинэ text бүр энэ дүрмийг дагах ёстой.
