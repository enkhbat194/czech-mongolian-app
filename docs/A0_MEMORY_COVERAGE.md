# A0 Memory Coverage v1

## Сургалтын гол дүрэм

Апп нь шинэ үгийн тоогоор биш, сурагч бодит нөхцөлд санаж ашиглаж чадах хэллэгээр ахиц хэмжинэ.

Нэг идэвхтэй хэллэг дараах замаар явна:

1. Шинэ карт дээр сонсох, утгыг харах
2. Сонсож утгыг таних
3. Монгол утгаас Чех хэллэгийг сэргээх
4. Нөхцөлд зөв сонгох эсвэл өгүүлбэр бүтээх
5. Богино харилцан ярианд ашиглах
6. Дараагийн хичээлийн эхэнд carryover review-д дахин сэргээх
7. Дараагийн хугацаат review-д дахин орох

## Ангилал

### Идэвхтэй хэллэг

Суралцагч өөрөө хэлж, бодит ярианд ашиглах ёстой. Эдгээр нь carryover review болон дараагийн хичээлүүдэд заавал орно.

Жишээ:

- `Dobrý den.`
- `Jmenuji se …`
- `Jsem z Mongolska.`
- `Nerozumím.`
- `Mluvte prosím pomalu.`
- `Potřebuji vodu.`
- `Nemám kartu.`

### Дэмжих үг

Эхний шатанд бүтэн хэллэг дотор танихад хангалттай. Дараа нь илүү олон нөхцөлд дахин гарч байж идэвхтэй хэрэглээ рүү шилжинэ.

Жишээ:

- `z`
- `vy`
- `pomalu`
- `něco`
- `kartu`

## A0.1 засвар

Дараах хэллэгүүд өмнө нь карт, сонголт дээр харагдаад ярианд дутуу орж байв. Одоо богино ярианд нэмэгдсэн:

- `Ano, děkuji.`
- `Na shledanou.`

A0.1-ийн идэвхтэй хэллэгүүд A0.2 эхлэхийн өмнө заавал сэргээгдэнэ.

## A0.2 засвар

Дараах хэллэгүүдийг ярианд ашиглуулах давталт нэмэгдсэн:

- `Potřebuji telefon.`
- `Chci vodu.`
- `Chci tohle.`
- `Nemám peníze.`

## Carryover review дүрэм

Шинэ хичээлийн эхэнд өмнөх хичээлийн идэвхтэй хэллэгээс 3-ыг сонгоно.

Сонголтын дараалал:

1. Өмнө огт сэргээгдээгүй хэллэг
2. Буруу хариулсан хэллэг
3. Хугацаа нь болсон хэллэг
4. Агуулгын хувьд хамгийн хэрэгцээтэй seed хэллэг

Анхны A0.2 review:

1. `Dobrý den.`
2. `Jmenuji se …`
3. `Jsem z Mongolska.`

Дараагийн review-д `Nerozumím.`, `Mluvte prosím pomalu.`, `Děkuji.` зэрэг ээлжилж орно.

## Одоогийн хязгаар

Carryover review нь одоогоор review доторх зөв/буруу хариултыг phrase memory-д хадгална. Дараагийн алхам нь үндсэн хичээлийн бүх дасгал, харилцан ярианаас phrase-level алдааг шууд phrase memory-д бичих явдал юм.
