# Czech–Mongolian App — Product Vision V1

Огноо: 2026-07-17

## 1. Бүтээгдэхүүний тодорхойлолт

Энэ апп нь ерөнхий үг цээжлүүлэх апп биш.

Монгол хэлтэй, Чехэд амьдрах эсвэл ажиллахаар очих насанд хүрсэн хэрэглэгчийг бодит нөхцөлд Чехээр ойлгож, хариулж, асуудлаа шийдэж чаддаг болгох **mobile-first, offline-first survival Czech coach** байна.

Үндсэн амлалт:

> Хэрэглэгч өдөр бүр 10–15 минут сураад, Чехэд тохиолдох бодит нөхцөлд хэрэглэх өгүүлбэрээ сонсож, хэлж, хариулж сурна.

## 2. Зорилтот хэрэглэгч

- Монгол хэлтэй насанд хүрсэн эхлэгч
- Чех хэл огт мэдэхгүй эсвэл маш бага мэддэг
- Чехэд ажиллах, гэр бүлтэйгээ нэгдэх, өдөр тутмын амьдралд орох хэрэгцээтэй
- Удаан онол унших биш, шууд хэрэглэж болох хэллэг хүсдэг
- Интернет тогтмол бус үед ч сурах шаардлагатай

## 3. Өрсөлдөх байрлал

Апп дараах гурван давуу талыг нэг системд нэгтгэнэ:

1. **Тоглоомчилсон ахиц** — богино хичээл, зам, түгжээ, урамшуулал, өдөр тутмын дадал.
2. **Ярих төвтэй сургалт** — хэллэг сурах → давтаж хэлэх → бодит харилцан ярианд хэрэглэх.
3. **Монгол хүнд зориулсан тайлбар** — Чех хэлний логикийг Монгол хүний ойлголт, нийтлэг алдаатай холбож тайлбарлах.

## 4. Бүтээгдэхүүний зургаан тулгуур

### 4.1 Бодит нөхцөл

Хичээл бүр нэг бодит mission (зорилтот нөхцөл)-той байна.

Жишээ:

- хил, нисэх буудал
- мэндлэх, өөрийгөө танилцуулах
- зам асуух
- ажил дээр заавар ойлгох
- дэлгүүр, кафе
- байрны асуудал
- эмийн сан, эмч
- утсаар мэдээлэл авах
- аюулгүй байдал

Ганц үг шидсэн хиймэл асуулт биш, бодит хүн хоорондын өгүүлбэр ашиглана.

### 4.2 Native-audio-first

Сурагчид харагдах бүх Чех үг, хэллэг, диалогийн мөр тогтвортой `audioId`-тай байна.

Production дараалал:

1. Azure/ElevenLabs Czech neural TTS ашиглан лицензтэй анхны бүрэн аудио багц гаргах.
2. Төрөлх Чех хүнээр текст, өргөлт, хурд, байгалийн хэллэгийг QA хийх.
3. Гол диалог болон хамгийн их давтагдах өгүүлбэрүүдийг төрөлх Чех хүнээр дахин бичүүлэх.
4. Төхөөрөмжийн browser TTS-ийг зөвхөн fallback болгон үлдээх.

Интернетээс санамсаргүй MP3 татаж ашиглахгүй. Эх сурвалж, лиценз тодорхойгүй аудио production-д орохгүй.

### 4.3 Visual scene system

Хичээл зөвхөн хар card жагсаалт байхгүй.

Mission бүр:

- нэг үндсэн background scene
- 1–3 дүр
- хэрэглэгчийн харах байрлал
- нөхцөл тайлбарлах жижиг объектууд
- dialogue state-аас хамаарч өөрчлөгдөх expression/pose
- audio тоглоход waveform эсвэл mouth pulse
- зөв/буруу хариултад богино motion feedback

Visual style:

- mobile дэлгэцэд цэвэр харагдах 2D/2.5D vector illustration
- Чех хот, ажил, байр, дэлгүүрийн бодит орчин
- насанд хүрэгчдэд зориулсан, хүүхдийн хэт тоглоомын дүрслэлгүй
- нэг дэлгэц дээр хэт олон элементгүй
- dark UI дээр дулаан accent болон тод scene card

### 4.4 Speak-first loop

Хичээлийн гол мөчлөг:

1. **See the scene** — нөхцөлийг зураг, богино Монгол тайлбараар ойлгоно.
2. **Hear** — төрөлх дуудлагатай өгүүлбэр сонсоно.
3. **Notice** — гол үг, бүтэц, утгыг харна.
4. **Repeat** — чангаар давтаж хэлнэ.
5. **Respond** — нөхцөлд зөв хариу сонгоно эсвэл хэлнэ.
6. **Role-play** — богино харилцан яриаг хэрэглэгчийн дүрээр гүйцэтгэнэ.
7. **Review** — сул хэллэгийг дараа дахин гаргана.

### 4.5 Adaptive memory

Одоо байгаа canonical SRS state-ийг хадгална.

Давталт нь:

- үзсэн эсэх
- зөв/буруу оролдлого
- төөрөгдүүлсэн хэллэг
- хариулах хугацаа
- mastery tier
- due date

дээр үндэслэнэ.

Шинэ тусдаа memory store үүсгэхгүй.

### 4.6 Offline trust

Хэрэглэгчийн итгэл алдагдаж болохгүй.

Production шаардлага:

- татсан lesson data offline ажиллана
- татсан аудио offline тоглоно
- progress localStorage-д versioned migration-тай хадгалагдана
- progress export/import байна
- update хийхэд хэрэглэгчийн явц устахгүй
- missing asset үед дэлгэц crash хийхгүй

## 5. A0-ийн бодит статус

A0.1–A0.15 нь зөвхөн санааны туршилт биш. Runtime lesson data, dialogue, exercise, SRS, audit болон үндсэн flow орсон.

Гэхдээ энэ нь одоогоор **technical curriculum foundation** байна. Дараах product layer дутуу:

- нэгдсэн visual identity
- mission scene illustration
- character system
- production MP3 audio
- бодит pronunciation assessment
- polished onboarding
- premium-level lesson transitions
- final user testing
- progress backup

Тиймээс одоогийн кодыг хаяж дахин эхлэхгүй. Суурь дээр нь experience layer нэмнэ.

## 6. Product quality bar

A0 release-ийг дараах үед өрсөлдөхүйц гэж үзнэ:

- хэрэглэгч эхний 30 секундэд аппын зорилгыг ойлгоно
- A0.1 эхлэхэд зурагтай бодит нөхцөл шууд харагдана
- Чех мөр бүр тогтвортой аудиотой
- хэрэглэгч 60 секундийн дотор анхны Чех өгүүлбэрээ хэлнэ
- хичээл бүрийн төгсгөлд нэг бодит чадвар эзэмшсэн байна
- UI нь prototype биш нэг дизайн системтэй байна
- A0.1–A0.15 ижил чанарын загвартай байна
- offline үед үндсэн flow ажиллана
- progress алдагдахгүй
- iPhone дээр overflow, mic, audio, safe-area асуудалгүй

## 7. Хийхгүй зүйл

Одоохондоо:

- A1 контент эхлүүлэхгүй
- бүх хуучин кодыг дахин бичихгүй
- backend account system түрүүлж хийхгүй
- 3D дүр, хүнд game engine оруулахгүй
- лицензгүй YouTube/сайтын аудио ашиглахгүй
- бүх 15 хичээлийн зураг, animation-ийг нэг дор үйлдвэрлэхгүй

## 8. Хэрэгжүүлэх стратеги

### Phase 1 — Gold vertical slice

A0.1-ийг production quality жишиг хичээл болгоно.

Үүнд:

- scene illustration
- character dialogue
- polished transitions
- MP3 manifest
- speaking flow
- reward sequence
- iPhone smoke test

бүгд орно.

### Phase 2 — System extraction

A0.1 дээр батлагдсан visual, audio, scene, animation component-уудыг reusable system болгоно.

### Phase 3 — A0 rollout

A0.2–A0.15-ийг 3–4 хичээлийн багцаар шинэ системд шилжүүлнэ.

### Phase 4 — Release hardening

Offline, progress backup, asset audit, performance, accessibility, final Czech QA, App Store/PWA release бэлтгэл.

## 9. Хэрэглэгчийн оролцоо

Хэрэглэгч кодын шийдвэр бүрийг гаргах шаардлагагүй.

Хэрэглэгч зөвхөн дараах бүтээгдэхүүний шийдвэрт оролцоно:

- visual direction сонгох
- дүрийн өнгө төрхийг батлах
- Монгол тайлбарын өнгө аясыг батлах
- mission урсгал бодит эсэхийг шалгах
- iPhone дээр smoke test хийх

Техникийн дотоод задаргаа, файл, component, test, audit-ийг AI өөрөө хариуцна.
