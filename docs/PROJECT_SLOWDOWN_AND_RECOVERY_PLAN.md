## 4. Дахин давтахгүй дүрмүүд (Prevention rules)

1. **Дүрэм эхэлж, контент дараа**: шинэ түвшний (A1) контент бичихээс ӨМНӨ pedagogy guardrails + audit скриптүүд бэлэн байна.
2. **Зөв хариултын байрлалыг өгөгдөлд бус runtime-д шийднэ**: authoring үед байрлал чөлөөтэй, харин `audit:position` үүрд CI-д байна.
3. **Хоёр дахь хуулбар = зогс**: ижил функц 2 дахь файлд хуулагдах үед shared util руу гаргана (аудит үүнийг барьдаг болсон).
4. **Аудит нэмэхгүйгээр төрөл нэмэхгүй**: шинэ дасгалын төрөл/талбар орвол contract audit хамт өргөжинө.
5. **UI дотор сургалтын контент bichихгүй**: бүх үг/хэллэг data файлд, memory target-тай холбоотой байна.
6. **Snapshot баримт = скрипт**: гар баримт биш, дахин үүсгэж болдог generator (Content Audit шиг).
7. **Batch бүр нэг зорилготой, нэг commit цуврал**: доорх batch size дүрмээр.

## 5. Шинэ ажиллагааны загвар (Operating model)

| Тал | Хариуцлага |
|---|---|
| **GPT** | Контент зохиомж (Czech/Монгол текст, диалог, final mission), pedagogy шийдвэрийн санал, контентын repair batch, PR body/status хөтлөлт |
| **Claude** | Engine/store код, тест ба audit скрипт, strict/чанарын hardening, read-only risk report, batch бүрийн давхар шалгалт (`npm run check` + diff уншилт) |
| **Хэрэглэгч (Enkhbat)** | Контентын эцсийн шийдвэр (flag: KEEP/REPAIR/REMOVE/REPLACE), batch approve, төхөөрөмж дээрх smoke test, merge шийдвэр |

Зарчим: **нэг branch дээр нэг удаад нэг бичигч** — GPT контент бичиж байхад Claude engine-д, эсрэгээрээ. Давхцах файлд орохын өмнө нөгөө талдаа мэдэгдэнэ.

## 8. Batch бүрийн Definition of Done

- **Report-only**: баримт docs/-д; товч summary өгсөн; хэрэглэгч APPROVED гэсэн; commit хийгдсэн.
- **Code batch**: `npm run check` exit 0 (13 шат); шинэ логик бол unit тест нэмэгдсэн; feat branch руу push; PR body шинэчлэгдсэн.
- **Content repair batch**: flag-тай мөр бүр шийдвэрийн дагуу өөрчлөгдсөн; audit warning тоо буурсан; Czech текст өөрчилсөн бол vocabulary/contract audit ногоон.
- **Smoke test batch**: iPhone дээр тухайн flow бүрэн дамжсан; илэрсэн асуудал бүр Issue/тэмдэглэл болсон.

## 9. Зогсоох нөхцөл (Stop conditions)

1. **Scope хэтэрвэл зогс**: нэг batch 6+ файл, эсвэл 2+ өөр сэдэв хөндөж эхэлбэл — хувааж, шинэ batch болго.
2. **Контентын шийдвэр гараагүй бол код бичихгүй**: flag TODO байгаа мөрөнд түшиглэсэн feature хийхгүй.
3. **`npm run check` улаан бол дараагийн ажил эхлэхгүй**: эвдэрсэн gate дээр давхарлаж ажиллахыг хориглоно.
4. **Хоёр AI нэг файлд зэрэг орохоор бол зогс**: эхлээд хэн эзэмшихээ тохирно.
