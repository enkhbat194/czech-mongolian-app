# A0.8–A0.15 бичвэр баталгаажуулалт v0.1

Энэ файл нь A0.8–A0.15 хичээлүүдийг app-ийн өгөгдөл болгохоос өмнө **бичвэрээр шалгаж батлах** ажлын эхний хувилбар.

## Энд хэрэглэж байгаа нэршлийн энгийн тайлбар

- **Бичвэр баталгаажуулалт** — хичээлийн Чех өгүүлбэр, Монгол утга, ярианы үйл явдал, шинэ/давтах үгийн ялгааг code руу оруулахаас өмнө шалгах ажил.
- **Шинэ card** — тухайн хичээл дээр анх удаа сурагчид шинэ зүйл болгож заах үг/хэллэг.
- **Давтлага** — өмнө орсон хэллэгийг энэ хичээлийн ярианд дахин ашиглах. Энэ нь зөв; давталтгүй бол хэл суухгүй.
- **Дахин тайлбарлах шаардлагатай** — өмнө орсон боловч шинэ нөхцөл, шинэ хэлбэр, шинэ хэрэглээтэй тул богино тайлбар дахин өгөх хэрэгтэй зүйл.
- **Сонсож ойлгох хэллэг** — сурагч өөрөө хэлэх албагүй, харин нөгөө хүн/ажилтан хэлэхэд ойлгох ёстой хэллэг.
- **Өөрөө хэлж сурах хэллэг** — сурагч өөрөө амьдрал дээр хэлж чаддаг болох ёстой хэллэг.

## Ерөнхий хатуу зарчим

1. Давталтыг хориглохгүй. Сургалтад хэрэгтэй бол өмнөх үгийг дахин хэрэглэнэ.
2. Гэхдээ нэг хэллэгийг хэрэггүйгээр олон шинэ card болгож давхар бүртгэхгүй.
3. Яриа бүр бодит үйл явдалтай байна: эхлэл → зорилго/асуудал → шийдэл → хаалт.
4. Монгол орчуулга сурагч шууд ойлгохоор байна. Хэт үгчилсэн орчуулга хэрэглэхгүй.
5. Staff буюу нөгөө хүний хэллэгийг сурагчид хүчээр хэлүүлэхгүй; эхлээд сонсож ойлгуулах хэлбэрээр өгнө.
6. A0 түвшинд хэт урт, хэт дүрмийн өгүүлбэр шахахгүй.
